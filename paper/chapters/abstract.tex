\begin{abstract}
Slow faults---transient network delays, disk stalls, and CPU
throttling---trigger catastrophic failures in production distributed
systems at severities far below monitoring thresholds. We present
\system{}, a noise-tolerant boundary estimation system that automatically
discovers the minimal fault severity that destabilizes a given system. Unlike
exhaustive grid approaches that test pre-defined severity values, \system{}
uses greedy dimensional minimization with composable probing strategies to
converge on precise vulnerability boundaries with measured confidence.

We evaluate \system{} across 10 distributed systems (etcd, ZooKeeper,
MongoDB, Redis, TiKV, CockroachDB, Cassandra, HBase, Kafka, Hadoop) and
5 fault types (50 configurations). Our key empirical finding: all five
consensus-based systems exhibit catastrophic failure at network delays
$\leq$19.5\,ms---250$\times$ below industry alerting thresholds (1--5\,s)
and invisible to every production monitoring system we surveyed. \system{}
discovers these boundaries using 52\% fewer trials than exhaustive grids,
matches Bayesian optimization on precision while avoiding GP overhead, and
finds vulnerabilities outside pre-defined grid ranges in 14\% of
configurations. Multi-fault interactions reduce individual boundaries
by 22--50\%, demonstrating that single-fault testing yields optimistic
safety margins. Boundaries are stable (CV$<$5\%) and validated with
$>$97\% confidence separation.
\end{abstract}
